## Naming convention

Please follow this when you push a lab:

- **Folder:** `lab-NN-short-topic-your-name`, with a two-digit number and lowercase words joined by hyphens. Example: `lab-02-sketch-a-flow-jane-doe`.
- **Inside each lab folder:**
  - `README.md` opens with `# Lab NN · Title`, then an `**Author:** Your Name` line.
  - `notes.md` holds one line per try: idea → what changed → keep or drop.
  - Code and other files keep the names the lab gave them.
- **Root README:** add your row to the table above.
- Don't commit `.DS_Store` or other system files. `.gitignore` already covers them.
